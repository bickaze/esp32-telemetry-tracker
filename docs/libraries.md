Библиотеки (Arduino Library Manager):

- TinyGPSPlus
- Adafruit ADXL345
- Adafruit ADS1X15

Плата: ESP32 Dev Module.

Подключение:

- NEO-6M: RX → GPIO16, TX → GPIO17
- ADXL345, ADS1115: SDA → 21, SCL → 22
- microSD: CS → 5, SCK → 18, MISO → 19, MOSI → 23
